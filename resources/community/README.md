# Decisões, falhas e incidentes

Esta pasta oferece formatos comuns para comparar arquiteturas e transformar falhas em controles
testáveis.

- `caso-de-decisao.md`: por que uma arquitetura foi escolhida, reduzida ou descartada;
- `aprendizado-de-incidente.md`: relato sanitizado e sem culpa;
- `indice.md`: catálogo de contribuições aceitas.

Uma contribuição não precisa terminar com IA. Casos em que regras, busca, formulário ou workflow
foram suficientes são especialmente úteis para tornar visível a decisão de não usar agentes.
